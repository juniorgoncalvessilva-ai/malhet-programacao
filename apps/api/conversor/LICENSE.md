# Conversor DWG → DXF (malhet-conversor-dwg)

Este programa é distribuído sob a **GNU General Public License v3.0 ou posterior**, porque usa o LibreDWG
(`@mlightcad/libredwg-web`, GPL-3.0). Ele é um programa separado: a API do Malhet apenas o executa como processo e lê o
arquivo DXF que ele gera. O restante do Malhet não é derivado dele.

Código-fonte do LibreDWG: https://www.gnu.org/software/libredwg/ · https://github.com/mlightcad/libredwg-web
